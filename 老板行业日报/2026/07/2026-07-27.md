## [英伟达与 SK 海力士签署多年 HBM 合作协议](https://news.google.com/rss/articles/CBMickFVX3lxTE1PUXp1MUxXYWFDdVJnTlk3MzJLMk1FLW9ZV0lYQTZlNEhnd2NrVHBJLW5wN0RrNjFENlc5emRNaEZrVEp6bllRY3VZTTByYjQ5V3pvaWZWQ3E4dkJ3cWpCNktzdTNxMkV2aXViZk1uZGFiUQ?oc=5) ⭐️ 9.0/10

英伟达与 SK 海力士签署了一项多年技术合作协议，重点围绕用于 AI GPU 的高带宽内存（HBM）技术。 此次合作巩固了 SK 海力士作为英伟达关键 HBM 供应商的地位，确保大型 AI 模型训练和推理所需的高性能内存稳定供应，也凸显了 HBM 在 AI 硬件供应链中的战略重要性。 高带宽内存是一种 3D 堆叠 DRAM 架构，在比传统内存功耗更低的同时提供巨大吞吐量。该协议很可能涵盖下一代 HBM3 或 HBM4 技术。

rss · Google News - AI 前沿 · 7月26日 04:43

**背景**: 高带宽内存（HBM）是一种专用内存技术，通过硅通孔和宽数据路径垂直堆叠 DRAM 芯片，提供比 DDR 或 GDDR 内存高得多的带宽。对于英伟达 H100 及即将推出的 B100 等 AI 加速器，HBM 至关重要，因为这些加速器需要巨大的内存带宽才能高效处理大数据集。SK 海力士一直是 HBM 的主要供应商，该协议确保了长期合作。

## [揭秘中国 LLM 令牌中转市场欺诈链](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything) ⭐️ 8.0/10

Matt Lenhard 的调查揭示了中国一个灰色市场，该市场通过滥用免费试用、窃取凭证和退单攻击，以官方定价的 94%-98%折扣转售 LLM 令牌。该市场使用开源代理软件，如 one-api 和 new-api，来汇聚和代理 API 密钥。 这个欺诈市场破坏了 LLM API 的安全性和成本模型，使用户面临数据窃取和模型蒸馏风险。它凸显了供应商迫切需要实施更严格的 API 密钥配额和更好的欺诈检测。 转售者通过滥用免费试用、未受保护的支持机器人、窃取的信用卡和退单攻击来实现折扣。代理软件 one-api 及其分支 new-api 本是合法工具，现被用于欺诈，汇聚凭证并负载均衡请求。

rss · Simon Willison · 7月26日 19:30

**背景**: LLM API 令牌允许访问 GPT-4、Claude 等模型，通常按令牌计费。中国出现了一个提供深度折扣令牌的二级市场，这些令牌通常通过欺诈手段获取。开源代理（如 one-api）简化了密钥汇聚和路由，助长了这一灰色经济。
