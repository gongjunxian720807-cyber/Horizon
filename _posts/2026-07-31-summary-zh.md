## [GitHub 推出堆叠式拉取请求公共预览版](https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/) ⭐️ 8.0/10

GitHub 推出了堆叠式拉取请求（PR）的公共预览版，允许开发者创建相互依赖的 PR，这些 PR 可以独立审查和合并。 此功能简化了大变更的代码审查流程，使复杂修改更易于分解为可管理的堆叠，提升了开发者的生产力和协作效率。 该功能通过 \`gh stack\` CLI 扩展使用，但用户报告整个堆叠的合并功能在许多情况下存在问题，且使用压缩合并时每个 PR 需要重新审批。

hackernews · tomzorz · 7月30日 16:26 · [社区讨论](https://news.ycombinator.com/item?id=49112232)

**背景**: 堆叠式拉取请求允许开发者将大的代码变更拆分为一系列相互依赖的小型 PR。每个 PR 以堆叠中的下一个为目标，可以依次审查和合并。这种方法在某些开发工作流中很常见，但此前 GitHub 并未原生支持。
