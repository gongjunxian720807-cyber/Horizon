## [Chrome 网上应用店移除 Manifest V2 扩展，包括 uBlock Origin](https://webiterate.dev/google-removed-extensions-ublock-origin-108/) ⭐️ 8.0/10

谷歌已经从 Chrome 网上应用店移除了所有剩余的 Manifest V2（MV2）扩展，包括广受欢迎的广告拦截器 uBlock Origin。在 Chrome 138 或更早版本上已安装的扩展仍然保留，但不再获得更新，也无法从商店重新安装。 这一变化影响到数百万依赖 uBlock Origin 拦截广告和防范恶意广告的用户。它进一步巩固了谷歌对浏览器扩展分发渠道的控制，并推动用户转向 Firefox 等替代方案，因为 uBlock Origin 在那里仍能完整发挥作用。 Manifest V3 用 service worker 取代长期后台页面，并禁止远程托管代码，从而限制了 uBlock Origin 依赖的拦截 API。根据 MV2 弃用时间表，在 Chrome 138 或更早版本上已安装的扩展仍会保留，但不会获得更新，一旦移除就无法重新安装。

hackernews · twapi · 8月31日 21:10 · [社区讨论](https://news.ycombinator.com/item?id=49514878)

**背景**: Manifest V2（MV2）和 Manifest V3（MV3）是 Chrome 扩展的两种架构。MV3 于 2020 年推出，旨在提升安全性和性能，但它限制了 webRequest 的阻塞版本等 API，而广告拦截器正是用这些 API 在内容加载前进行过滤。uBlock Origin 是一款免费、开源且广泛使用的内容拦截工具，在 Firefox 上功能完整，但在 MV3 下无法提供同等功能，因此其开发者建议用户继续使用 Firefox 以获得完整支持。
